# aexo Client

A mobile-first browser client shell themed for Eaglercraft 26.3. This project is intentionally a customized launcher/UI layer rather than an imported game source fork. It is designed to be safe and incremental for use on iPhone via GitHub's web UI.

## What this repo contains

- Custom aexo Client branding and main menu
- Dark theme with icy-blue accents
- Mobile-friendly layout for small screens
- Browser-based launcher shell and settings mockup
- HUD and performance toggles for a lightweight mobile experience
- A placeholder configuration area for a legally verified Eaglercraft 26.3 source or hosted build

## Important legal note

Before importing or modifying any Eaglercraft source, assets, or builds, verify:

- the original upstream repository or mirror
- its license terms
- whether the project includes copyrighted Mojang/Microsoft code or assets
- whether redistribution is allowed under the upstream terms

This repository does not claim the project is fully legal or redistributable. It is a starter UI and workflow scaffold only, designed to keep the work transparent and reversible until source provenance is confirmed.

## Mobile-friendly workflow

1. Open this repo in GitHub on your iPhone.
2. Edit files in small changes.
3. Keep the UI working before adding more features.
4. Test the page in iPhone Safari.
5. Only import upstream Eaglercraft 26.3 source after confirming the license and download origin.

## Local preview

Open `index.html` in a browser, or serve the folder locally with a simple static server if desired.
